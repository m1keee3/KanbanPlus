# KanbanPlus

## Функциональные требования

- Создание доски 
	
- Подключение к существующей доске по ID
	
- Управление колонками (добавление, переименовывание, удаление)
	
- Управление карточками (CRUD)
	
- Перемещение карточек между колонками
	
- Real-time синхронизация
	
- Обработка запросов в несколько потоков
	
- Сохранение состояния
